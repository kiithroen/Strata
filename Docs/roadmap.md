# 로드맵

## 지금 상태

Vite + TypeScript + Three.js 웹 앱 틀과 위젯 갤러리가 있다. 첫 위젯인 노트 카드가 구현돼 있다([widgets.md](widgets.md)).

- 확인한 것: 단위 테스트(주사율 무관성, 펼친 카드의 화면 맞춤, 배치 범위), 데스크톱 브라우저에서 세로·가로에 가까운 화면비의 펼치기·닫기 캡처
- 확인하지 않은 것: 폰 실기기에서의 탭 반응, 120Hz에서의 움직임, 폴더블 접기·펼치기 중 화면 맞춤

## 다음 작업

차례대로 한다. 각 위젯은 갤러리 데모, 단위 테스트, 화면 캡처 확인까지 마쳐야 끝난다.

1. **노트 카드 실기기 확인**: 폰에서 갤러리를 열어([development.md](development.md) "폰에서 열기") 탭 반응, 카드 글자 가독성, 펼치기 속도를 본다. 고칠 값은 `src/config.ts`에서 고친다.
2. **시간축 위젯**: 시간을 화면 안쪽 깊이로 펼친 축. 눈금, 날짜 라벨, 지금 위치 표시. 시간 → 깊이 변환과 축척 단계(연·월·일·노트)를 순수 로직으로 두고 테스트한다. 노트 카드의 자리를 `field.ts`의 흩기 대신 시간축이 정하게 바꾼다.
3. **카메라·제스처 위젯**: 한 손가락 끌기(시간 이동, 관성), 핀치(시간 축척, 손가락 아래 시점 고정, 놓으면 단계 스냅). 지금 `input/tap.ts`의 탭 판정과 함께 하나의 제스처 해석기로 묶는다. 제스처 해석은 포인터 이벤트 열을 넣으면 결과가 나오는 순수 로직으로 두어 테스트한다.
4. **후처리 위젯**: 화면 전체 디더링, 주사선, 색수차, 잡음. 효과마다 켜고 끈다.
5. **노트 보기**: 펼친 카드에서 사진 전체 보기로 넘어가는 전환.

그 뒤에 실제 데이터로 넘어간다: 사진 가져오기(EXIF 날짜), 저장(OPFS 또는 IndexedDB와 저장소 영구화), 캡션 입력(2D 화면).
