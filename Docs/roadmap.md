# 로드맵

## 지금 상태

Vite + TypeScript + Three.js 웹 앱 틀과 위젯 갤러리가 있다. 주 화면은 우주 보기(`cosmos`)다. 시간 묶음은 나선팔 위의 빛나는 노드이고, 노드에서 노트 점이 방사형 선으로 뻗으며 한 단계 위 허브에 가지로 이어진다. 노트 몇 장은 노드 둘레를 돌풍에 날리는 흰 종이로 날아다닌다. 시간 모델은 시간축 위젯이, 종이는 노트 카드 위젯이 맡는다([widgets.md](widgets.md)).

- 확인한 것: 단위 테스트(주사율 무관성, 달력 눈금·묶음, 나선, 허브·노트 점 배치, 종이 비행·돌풍·뒹굴기, 묶음이 바뀔 때의 이동), 데스크톱 브라우저 캡처(우주 보기 연·월·일 단계, 노드 탭으로 들어가기, 종이 펼치기·닫기)
- 확인하지 않은 것: 폰 실기기에서의 탭 반응·120Hz 움직임·폴더블 접기와 펼치기, 실기기 성능(먼지·성운의 화면 채움 비용, 카드 텍스처 메모리)

## 다음 작업

차례대로 한다. 각 위젯은 갤러리 데모, 단위 테스트, 화면 캡처 확인까지 마쳐야 끝난다.

1. **카메라·제스처 위젯**(우주 보기에 붙인다): 한 손가락 끌기(시간 이동, 관성), 핀치(로그 축척, 손가락 아래 시점 고정, 놓으면 `nearestLevel`로 스냅). 지금 `input/tap.ts`의 탭 판정과 함께 하나의 제스처 해석기로 묶는다. 제스처 해석은 포인터 이벤트 열을 넣으면 결과가 나오는 순수 로직으로 두어 테스트한다. 끄는 동안에는 `AxisController.current`를 바로 움직이고, 놓을 때만 목표로 붙인다. 임시 단추(`axisHud.ts`)는 이때 뺀다.
   - 손가락 아래 시점 고정: 핀치 중심에서 가장 가까운 노드(없으면 초점면)의 시각이 축척이 바뀐 뒤에도 같은 깊이에 오도록 `focusTime`을 옮긴다.
   - 손가락이 닿아 있는 동안 공전이 멈추는 지금 동작을 끌기·핀치에도 그대로 둔다.
2. **실기기 확인**: 폰에서 갤러리를 열어([development.md](development.md) "폰에서 열기") 제스처 손맛, 종이 크기·속도와 탭 정확도(돌풍이 셀 때 너무 빠른지), 선 굵기, 은하 밀도, 프레임 속도를 보고 `src/config.ts`에서 고친다. 무거우면 먼지 수·성운 해상도·종이 격자 칸 수를 줄이고, 카드 텍스처는 아틀라스로 묶거나 거리별로 해상도를 낮춘다.
3. **가독성 보기**: 날리는 종이를 멈추고 읽기 쉽게 늘어놓는 보기. 우주 보기와 오가는 방법을 정한다.
4. **여러 해를 은하로**: 연 단계보다 더 축소하면 해마다 은하 하나로 모이고, 은하를 탭하면 그 해로 들어간다. 지금 나선팔 모델을 은하 하나의 안쪽으로 두고 바깥 단계를 하나 더 얹는다.
5. **후처리 위젯**: 화면 전체 블룸(노드 빛 무리, 선, 별), 디더링, 색수차. 효과마다 켜고 끈다. 카드 셰이더의 주사선·잡음과 겹치지 않게 정리한다.
6. **노트 보기**: 펼친 카드에서 사진 전체 보기로 넘어가는 전환.

그 뒤에 실제 데이터로 넘어간다: 사진 가져오기(EXIF 날짜), 저장(OPFS 또는 IndexedDB와 저장소 영구화), 캡션·태그 입력(2D 화면). 실제 사진은 디코딩이 비동기라 `PhotoSource.render`를 비동기로 바꾸고, 사진이 오기 전에는 테두리와 라벨만 그린 카드를 보인다.

### 다른 축(태그)

태그가 입력되면 날짜 대신 태그를 축으로 고를 수 있게 한다. 지금 우주 보기는 날짜에 묶여 있어서(`AxisController`의 시각·축척, 달력 단위 묶음, 시각 → 깊이) 그때 아래처럼 나눈다.

- **묶음 공급자**: 노트 목록을 받아 노드(키, 글자, 구성원, 위 노드, 정렬값)를 내는 인터페이스를 두고, 날짜 묶음을 그 구현 하나로 옮긴다. 태그 묶음이 두 번째 구현이다.
- **정렬값 → 깊이**: 날짜는 시각을 그대로 쓴다. 태그는 순서가 없으니 정렬값(가장 최근 노트 시각, 노트 수 등)을 정해 나선 위 깊이로 바꾼다.
- **여러 소속**: 날짜는 노트 하나가 노드 하나에 속하지만 태그는 여러 노드에 속한다. 종이는 소속 노드들 사이(가중 평균 자리) 둘레를 날고, 소속 노드마다 실을 압정에 맨다. 실 여러 가닥이 한 종이로 모이는 모양이 된다.
- **단계(확대·축소)**: 날짜는 달력 단위로 합치고 가른다. 태그는 태그 계층(상위 태그)이나 묶음 크기로 합치고 가른다.
