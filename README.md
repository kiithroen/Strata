# Strata

사진 노트가 3D 공간에 떠 있고, 손가락으로 시간축을 오가며 노트를 보는 개인용 노트앱이다. Three.js와 TypeScript로 만든 웹 앱이며, 지금은 UI 위젯을 하나씩 만들어 위젯 갤러리에서 확인하는 단계다.

배포본: <https://kiithroen.github.io/Strata/> (`main`에 푸시하면 GitHub Actions가 테스트·빌드 뒤 GitHub Pages에 올린다)

```bash
npm install
npm run dev
```
